Vexora Launcher

A modern Minecraft launcher built with Rust. 💜

Vexora is designed to be fast, lightweight, customizable, and easy to use, while providing all  tools you need for managing Minecraft instances.

✨ Features

-🎮 Minecraft instance management
-🔐 Microsoft account authentication
-🎨 Custom themes & customization
-👤 Skin management
-📦 Instance importing
-⚙️ Advanced launcher settings
-🧩 Modded Minecraft support
-🛠️ Logs & diagnostics
-🚀 Fast native Rust + GPUI interface
-🚧 Development

Vexora Launcher is currently in active development. Features and UI are still being improved and expanded.

🛠️ Built With
Rust
GPUI
Cargo
